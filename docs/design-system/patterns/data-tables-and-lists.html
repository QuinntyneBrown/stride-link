Pattern

Data tables and lists

No tables: a chronological plain-text log, short fact lists and three readouts, each built so the data copies and diffs cleanly.

Overview

Stride Link has no data tables. Its data is a stream (the packet log), a handful of facts about the run, three telemetry values and, in the browser's chooser, a short list of devices. Each has its own component, chosen so that copying the data out is lossless and diff-friendly.

DataComponentElement
Every frame and event of every runPacket logol.log__list inside div.log[role=log]
Device, model variant (and in set A, run and start time)Description list .factsdl
Verdict meaning, reason, next step.verdict__factsdl
Speed, incline, heart rateTelemetrydl.telemetry of .metric groups
Safety reminders.safety-listul
Devices in range (browser-native)Device listul of buttons

When to use

  • Use the log for anything time-ordered from the treadmill. Lines are plain text in the L2-038 format so a copy or export diffs cleanly: 12.3 TX f2 F0 A4 00 94 init.
  • Use a description list for a few labelled facts that belong together. Never a two-column table.
  • No sorting, filtering, selection, bulk actions or pagination. The log is strictly chronological (L2-037) and the DOM keeps the latest 500 entries while the export keeps all (L2-039); a page-through control would hide the newest frames.
  • No infinite scroll trigger. The log follows new entries while the tester is at the bottom and holds position when they scroll up (L2-039).
  • Set A's log legend (TX, RX, EV, “Times in ms since Connect”) and set B's (“TX written to f2”, “RX notified on f3 or f4”) are both unshipped; the shipped panel has a count caption only.

Responsive behaviour

  • Below 992 px the log is a panel at the end of the column with a 26 rem maximum height (--layout-log-height-mobile) and its own scroll.
  • From 992 px it fills the right column's height and scrolls independently while the left column stays put (L2-066).
  • Log text is 12 px below 576 px and 14 px from 576 px; long hex lines wrap anywhere inside the scroller, never widening the page (L2-064).
  • Facts keep two columns (term, value) at every width; values wrap with overflow-wrap: anywhere so long device names never overflow.

Accessibility

  • The log has role="log", the accessible name Packet log (L2-039) and aria-live="off"; it is focusable (tabindex="0") so keyboard users can scroll it.
  • Direction is in the text (TX, RX, EV), never colour alone; the mocks colour TX and RX labels, the shipped lines are uniform.
  • Device names and error text are text nodes (L2-051).
  • Description lists keep the native dt/dd semantics; screen readers announce term and value pairs.

Content

  • Log lines: <ms> <DIR> <char> <hex> <tag>, ms right-aligned to 10 characters with one decimal (L2-038).
  • Hex is uppercase two-digit bytes separated by single spaces: F0 A4 00 94.
  • Tags are lower case: init, unlock response, activation, keepalive, echo, belt.
  • Fact terms (shipped): Device, Model variant; variant values follow the log: standard, Stride 4.
