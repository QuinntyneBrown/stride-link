Navigation and page structure

One page, no navigation: structure is landmarks, a fixed reading order of panels and a focus order that matches it.

Overview

Stride Link is one page with no navigation: no routes, menus, tabs, breadcrumbs, sidebars or back behaviour. The “screens” in both mock sets are phases of that page (start, run, verdict, belt in set A; 27 named states in set B). Structure therefore means three things: landmarks, a fixed reading order, and a focus order that matches it (L2-060, L2-064).

  • Top bar (header.topbar.app-topbar): brand lockup and the privacy pill. It is not a navigation bar; it holds no links in the shipped page.
  • Main (main.app#main): the primary column of panels, then the packet log.
  • Stop bar (div.stop-bar[role=region][aria-label="Belt stop"]): fixed, only while the belt is active.
  • Footer (footer.footer.app-footer): version and commit.

When to use

Generic needIn Stride LinkWhy
Global navigation, sidebarNoneOne page, one task (L1). The privacy pill and brand need no links.
Tabs vs sub-pagesPanels stacked in a fixed orderEvery panel is relevant in the same run; hiding one behind a tab would hide a safety control.
Breadcrumbs, backNoneNo hierarchy. The browser's back leaves the page, which the browser's own leave-page prompt guards while the log is unexported.
Page header with actions.app__intro heading and subtitle, inside the status panel (shipped) or above it (both mock sets)The page's main action, Connect, lives in the Connection panel next to its notice.
Skip linkBoth mock sets start with Skip to content; the shipped page has noneRecorded as an open difference: the top bar is one stop, so the skip saves one Tab.

    States

    • Idle and error phases: status, connection, telemetry and log. No belt panel, no Stop bar.
    • Verdict Talks or Unlocked: the belt panel appears in position 4 with only its gate.
    • Belt active: the Stop bar is fixed to the bottom and the body reserves its height (body.has-stop-bar).
    • Second run: the same structure; the log keeps earlier runs under Run n headings (L2-041).
    • Headings differ across sources: the shipped verdict word is an h2, set B uses h3 and set A a p. The system follows the shipped outline: one h1, then h2 for every panel title and the verdict word.

    Accessibility

    • Landmarks: header (banner), main, the Stop bar region and footer (contentinfo).
    • DOM order is visual order at every width; the two-column layout is a grid, never reordered with order (L2-060).
    • Panels are section elements labelled by their visible titles with aria-labelledby.
    • The brand is a non-interactive span role="img" aria-label="Stride Link" as shipped; both mock sets make it a link to the default state, which on a one-page app is a link to itself.
    • Zoom is never disabled; the viewport meta is exactly width=device-width, initial-scale=1 (L2-067).

    Content

    • Page title (shipped): Treadmill smoke test; set A uses Connectivity smoke test. Subtitle (shipped and set A): Connect to an Echelon Stride and find out whether it answers.
    • Panel titles are one or two words in sentence case and render as uppercase overlines through CSS only: Status, Connection, Telemetry, Belt controls, Packet log.
    • Privacy pill (shipped and set A): Offline · nothing leaves this device; set B says Local only.
