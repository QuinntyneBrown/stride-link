Overview

Stride Link speaks to a tester standing next to a treadmill: plain, short, calm, and exact about bytes and safety. Its copy has two layers:

  • Fixed copy: every sentence that docs/specs/L2.md quotes. It is used character for character, apostrophes and full stops included, and lives in one messages module per area (src/ui/messages/). Tests compare it exactly.
  • Product copy: titles, labels, help text and status sentences that L2 does not quote. The shipped wording is the reference; the mock sets differ in places and those differences are listed on each component page.

The full microcopy library is on the content foundation; this page is about how copy is composed across components.

When to use

SituationVoiceExample
SafetyImperative, physical, no hedgingStop failed. Use the treadmill's stop button or safety key now.
FailureWhat happened, then what to doCouldn't connect within 10 seconds. Move closer to the treadmill and try again.
Environment problemState the cause, offer the remedyBluetooth is off or unavailable on this device. Turn it on to continue.
ResultOne word, then meaning and next stepTalks · Notifications arrive and no challenge was sent · Read telemetry; belt commands can be tried
ProgressPresent tense with an ellipsisConnecting to the treadmill…
RuleSay the limit and whySpeed is capped at 3 km/h for the smoke test.
OwnershipOne plain sentenceUse Stride Link only on a treadmill you own.

Structure

A verdict shows the composition at its most complete: label, word, meaning, optional reason, next step, one action. Every part is fixed by L2-036 except the label.

Responsive behaviour

  • Copy never changes with the viewport except one documented case: the privacy pill drops · nothing leaves this device below 576 px and keeps Offline.
  • Long fixed sentences wrap; they are never truncated or replaced by shorter text on phones.
  • Button labels stay one or two words so they never wrap at 320 px.

Accessibility

  • Accessible names match visible labels (L2-063): Stop belt, Packet log, Export log.
  • Symbols that read badly are kept out of names: the Esc key cap is aria-hidden; the empty telemetry dash is a visual placeholder.
  • States are words first (L2-062); colour and icons reinforce them.
  • Device names, errors and log text are inserted as text, never markup (L2-051).

Content

  • Sentence case everywhere; overline titles are uppercase through CSS only, so the source stays sentence case.
  • Numbers: speeds with two decimals and the unit after a space, 3.00 km/h; incline as a whole number with no unit; heart rate as 72 bpm; times as 20 s, 2.5 s, 10 seconds in full sentences.
  • Hex: uppercase byte pairs with single spaces, F0 E0 00 00 57 00 00 27.
  • Typographic apostrophes are not substituted: L2 uses ' and so does the page.
  • No exclamation marks, no “please”, no “oops”, no jokes near safety copy.
