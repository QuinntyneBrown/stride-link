Pattern

Empty and error states

The page's error pages are states of the one page, each carrying its L2 sentence and one way forward; empty states say what will appear and what fills them.

Overview

Stride Link has no routes, accounts or server, so the usual error pages (404, 403, 500, offline, maintenance) do not exist: the page is one offline file and it is always “found”. Its error pages are states of the one page: the browser cannot use Bluetooth, Bluetooth is off, the file is blocked from disk, or a connection step failed. Its empty states are the moments before data: an empty log, telemetry dashes, a chooser with nothing in range.

Formula for an error state: what happened, in the L2 sentence → what still works (Connect enabled or not) → one way forward (try again, turn Bluetooth on, open the hosted copy). Formula for an empty state: what will appear here + the action that fills it.

    Responsive behaviour

    • Error states never change layout: the status panel stays first and the rest of the page (telemetry dashes, empty log) remains in place below it.
    • Long L2 sentences wrap; the alert's icon stays top-aligned with the first line.
    • The hosted-copy link is a 44 px target at every width and wraps under the sentence on phones.

    Accessibility

    • Error sentences reach assistive technology through the polite status region; they are not assertive because nothing is at risk and the tester initiated the action.
    • Empty telemetry shows —. Set A adds a visually hidden “No reading yet” so a screen reader does not read “dash”; the shipped page renders the dash only. Recorded as an open difference.
    • Disabled Connect stays visible in the unsupported and Bluetooth-off states, so the tester sees what is unavailable; the sentence says why.
    • Device names in error and log text are inserted as text nodes, never HTML (L2-051); set B's edge state shows a hostile name rendered literally.

    Content

    • Use the L2 sentences verbatim; they already name the cause and the next step.
    • Empty-log copy (shipped): No entries yet. Press Connect to start a run. Set A says No frames yet. Press Connect to start a run; every frame sent and received appears here.
    • Do not apologise or blame: no “Oops”, no “You chose the wrong device”.
    • No illustrations: the page is a diagnostic tool and stays text-first and small (204,800-byte build limit).
