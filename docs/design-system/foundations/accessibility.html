Accessibility

Overview

The system targets WCAG 2.2 AA by construction, and Stride Link's L2-060 to L2-067 make several criteria stricter: 44 px targets for everything, a 64 px Stop, a 16 px body floor, polite announcements for status and verdict only. Every component page answers the same seven questions under Accessibility: role and pattern, keyboard, focus, labelling, contrast, motion and touch.

Interaction tokens

Every control height is a target token; the focus ring width and offset are tokens too.

Component contract

  1. Role and pattern: the native element or WAI-ARIA Authoring Practices pattern, named.
  2. Keyboard map: every key and its effect.
  3. Focus: where it starts, where it goes, how the ring looks.
  4. Labelling: what is named and what is announced.
  5. Contrast: the token pairs with live ratios in both themes.
  6. Motion: what moves and what reduced motion does.
  7. Touch: target sizes and hover alternatives.

Testing

  • check_contrast.py for every declared pair in both themes (172 checks, all pass).
  • check_design_system.py for labels, names, alt text, landmarks, headings and links on these pages.
  • In the product: axe-core in the Playwright suite for every state named in L2-062 (zero serious or critical violations), keyboard and touch runs, 200 % zoom, reduced motion. axe-core is never shipped.
  • Manual: Tab through each component page's examples, use a screen reader on the dialog and the log, zoom to 200 % and 400 %, emulate reduced motion and forced colours.
