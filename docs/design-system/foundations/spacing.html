Spacing

A 4 px scale in rem: small steps inside components, larger steps between them.

  • Overview
  • The scale
  • Inside and between
  • Padding by component
  • Usage

Overview

One 4 px scale, named by multiples of four (--space-4 = 16 px), in rem. Inside a component use --space-6 or less; between page parts use --space-4 and up. Spacing never scales with viewport width: a breakpoint swaps the token instead (margins and panel padding).

Usage

  • Pick from the scale; an off-scale value is drift. The mocks' only off-grid values are optical (0.1rem icon nudges, 0.3em lockup gap, em-based code padding) and are kept as written.
  • Prefer gap on the parent to margins on children.
  • Steps 10, 16 and 20 exist for completeness; no component uses them yet.

Accessibility

  • Every control is at least 44 × 44 px (L2-061), so adjacent targets never need extra spacing to meet WCAG 2.5.8.
  • The page reserves the Stop bar's height plus --space-2 at the bottom while the belt is active, so no content hides behind the bar (L2-064).
