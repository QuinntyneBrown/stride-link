Overview

Stride Link's colour comes from the logo sheet: ink #121418, paper #F4F2EE, muted #6B6E76, rule #DEDAD3 and signal orange #FF4F1F. Blue, green, amber and red carry status. Components never use a primitive: they read the semantic roles below, which the dark theme re-maps. Every pairing a component relies on is listed in tokens/contrast-pairs.json and checked in both themes.

  • Light is paper with ink text; dark mirrors the reversed lockup: ink with paper text.
  • Signal orange always carries ink text (5.6:1), never white (3.3:1). Orange text and links use signal-700 in light and signal-300 in dark.
  • A verdict or state is never colour alone: the word is always present (L2-062).

Usage

  • Use semantic tokens only; a primitive in component CSS is a bug.
  • Add a new pairing to contrast-pairs.json before shipping a component that introduces it, and re-run the check.
  • Orange fills always take ink text. Orange as text uses --color-fg-accent or --color-fg-link.
  • Status colour never stands alone: verdicts show the word, alerts an icon and text, the status line a sentence.
  • Do not add a new hue for a new meaning; reuse the four tones.

Accessibility

  • Body text is 16.5:1 on canvas in light and 16.5:1 in dark; every text pair is at least 4.5:1 (L2-062).
  • Edges that identify a control (inputs, checkbox, secondary button, primary edge), the focus ring and meaningful icons are at least 3:1.
  • prefers-contrast: more promotes default borders to strong and muted text to default (see Theming).
  • Forced-colours mode hands the focus ring to Highlight and borders and the mark arcs to CanvasText.
