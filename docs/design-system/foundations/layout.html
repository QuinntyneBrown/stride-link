Layout

Three page shapes from the L1-014 breakpoints: one column, a 720 px column, and two columns with the log on the right.

Overview

Stride Link is one page. Its layout has three shapes, set by the L1-014 breakpoints: one full-width column on phones, one column capped at 720 px on tablets (L2-065), and two columns with the packet log on the right from 992 px, capped at 1140 px from 1200 px (L2-066). While the belt is active a Stop bar is fixed to the bottom at every width (L2-045, L2-064).

Media queries use min-width in rem so they follow the user's font size. Custom properties cannot appear inside @media, so the values are repeated there by convention; tokens.css swaps --layout-columns, --layout-gutter and --layout-margin at 48rem and 62rem.

Page template

The order is fixed by L2-064: status and verdict, connection, telemetry, belt controls, log. From 992 px the log moves to the right column; nothing else moves.

Both mock sets follow this template. Set B wraps status in its own panel with an h1 intro above; set A puts the h1 intro above the panels too; the shipped page puts the h1 and subtitle inside the status panel. The template is the same in all three.

Usage

  • Use .app, .app__primary and .app__log (see Layout primitives); do not write new page grids.
  • Inside panels, use .stack and .cluster with spacing tokens.
  • Read --layout-margin for edge padding of anything full width (top bar, banner, Stop bar).
  • Drift: ui.css carries 40rem (dialog, toast) and 64rem (sidebar, top-bar menu) queries that are not L1-014 breakpoints. 40rem survives only in the mocks-only dialog and toast rules; the 64rem rules and .sidebar-layout are not part of this system, and the --layout-sidebar-width token .sidebar-layout references is not defined in either tokens file.

Accessibility

  • No horizontal page scroll from 320 px (L2-064); long hex wraps inside the log or scrolls inside it, never the page.
  • Zoom to 200 % at 1280 px reflows to the one-column shape with every function available (L2-067).
  • Reading order equals DOM order equals visual order at every breakpoint; the log moving right is a column change, not a reorder.
  • Portrait and landscape both work; nothing locks orientation.
