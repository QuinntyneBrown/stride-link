Typography

Inter Tight for words, JetBrains Mono for frames; a nine-step rem scale with a 16 px body floor.

Overview

Two families, both from the logo sheet and both bundled locally under the SIL Open Font License (assets/fonts/), so pages render offline: Inter Tight for everything readable and JetBrains Mono for frames, hex, device names and the packet log. Base body text is 16 px and never smaller (L2-067); nothing renders below 12 px.

Measure and numbers

  • Paragraphs cap at --layout-measure (65ch); status lines, notices and alerts opt out with max-width: none because they sit inside narrow panels already.
  • Numbers that change in place use font-variant-numeric: tabular-nums: telemetry values, counts, the Stop bar meta and the speed input, so digits do not jitter.
  • Headings use text-wrap: balance; paragraphs text-wrap: pretty.

Responsive type

  • Type uses fixed steps, never viewport units, so browser zoom to 200 % works (L2-067).
  • The page h1 is 30 px (--font-size-3xl) below 768 px and 36 px from 768 px.
  • Telemetry values are 24 px in the stacked layout below 576 px and 30 px in the three-up row.
  • Log lines are 12 px below 576 px and 14 px from 576 px.

Usage

  • Use a role shorthand, not a raw size. A new role is a new token, not a one-off.
  • Mono is for machine text only: hex frames, UUIDs, device names in facts, reasons, the log, version and commit. Never for prose.
  • Panel titles are overline (uppercase, 12 px bold, wide tracking) and are still real <h2> elements.
  • Sentence case everywhere; uppercase comes from CSS only, so screen readers read words, not letters.

Accessibility

  • Body text is 16 CSS px (L2-067 criterion 4); the smallest text is 12 px (captions, badges, narrow log lines).
  • All sizes are rem, so text resizes with the browser setting (WCAG 1.4.4).
  • Nothing breaks with WCAG 1.4.12 text spacing: components use min-height, not fixed heights, and wrap.
  • The verdict word is 48 px display text and also carries the meaning in words beside it (L2-062).
