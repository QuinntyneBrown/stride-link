Responsive

Mobile first: one column, a capped column, then two columns; every control 44 px at every width.

Overview

Mobile first: the base styles target a 320–575 px phone and three min-width queries add space and columns (36rem, 48rem, 62rem), with the 1140 px cap arriving at 75rem through --layout-container-max. Breakpoints come from L1-014 and the rules from L2-064 to L2-067. See Layout for the grid and caps.

Mobile-first rules

  • One column below 992 px, in the order status and verdict, connection, telemetry, belt controls, log (L2-064).
  • No horizontal page scroll at any width from 320 px; long hex wraps between bytes inside the log (L2-064 criterion 4).
  • Spacing never scales with viewport; a breakpoint swaps the token (margins 16 → 32 px, panel padding 20 → 24 px).
  • Type uses fixed rem steps, never viewport units, so zoom works (L2-067).
  • Fixed bottom elements (Stop bar) reserve their height in the body so nothing hides behind them.

Touch and pointer

  • Every control is at least 44 × 44 px at every width (L2-061); Stop belt is 64 × 64 px.
  • No function depends on hover; hover only changes colour (L2-061 criterion 2).
  • (pointer: coarse) is not used to grow targets: they are already large enough.
  • 100dvh sizes the sticky log column so mobile browser chrome does not clip it.
  • Escape (keyboard) and the always-visible Stop button (touch) are equal routes to stopping the belt.

Orientation and zoom

  • Portrait and landscape both work; 412 × 915 rotated to 915 × 412 keeps every control reachable (L2-067 criterion 1).
  • The viewport meta is width=device-width, initial-scale=1; never user-scalable=no or maximum-scale.
  • At 200 % zoom on a 1280 px window the page takes the 640 px one-column shape with no horizontal scroll (L2-067 criterion 3).

Accessibility

  • Reflow (WCAG 1.4.10): content works at 320 CSS px with no two-dimensional scroll; the log scrolls inside itself only.
  • Focus not obscured (WCAG 2.4.11): the body's bottom padding keeps focused controls clear of the Stop bar.
