Overview

A notice is a short, quiet, persistent line of advice that sits next to the control it concerns. Stride Link has one: the ownership notice by Connect, whose wording is fixed by L2-002: Use Stride Link only on a treadmill you own.

  • Use a notice for standing advice that is true in every state and needs no action.
  • Use an alert for something that just happened or blocks the next step.
  • Use the safety list for the belt rules, which are a list, not one line.

Anatomy

  1. Icon (mocks)18 px shield in --color-fg-accent, aria-hidden. Set A draws a shield with a check, set B a plain shield; the shipped notice has no icon.
  2. Text--text-body-sm in --color-fg-muted; the whole message.

Sizes

One size: 14 px text, 18 px icon, --space-2 between them. The line has no maximum width (max-width: none) so it can sit full width under the buttons.

States

Static text: no hover, focus, active or disabled state, and it never changes during a run.

Responsive behaviour

  • The text wraps beside the icon; the icon stays aligned with the first line (align-items: flex-start, 0.1rem nudge).
  • Placement differs between sources: the shipped page and set A put it under the panel title, before the actions; set B puts it after the actions. Both keep it inside the Connection panel, which L2-002 requires (“the area around Connect”).

Theming

Reads --color-fg-muted for text and --color-fg-accent for the icon; both have dark values in the theme block, so the notice needs no dark rule.

Accessibility

Role and pattern

A plain paragraph; no live region, because it never changes.

Focus

Never receives focus. It sits in reading order before or after Connect, so screen-reader users meet it when they reach the Connection panel.

Labelling

The sentence is the message; the icon is decorative and hidden.

Content

  • The ownership notice is fixed by L2-002: Use Stride Link only on a treadmill you own., with the full stop.
  • Other notices, if ever added, are one sentence in the second person, present tense, with no exclamation mark.
