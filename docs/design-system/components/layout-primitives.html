Overview

Layout primitives are the few classes that place everything else. There is one page, so there is one page layout (.app) plus three generic helpers.

PrimitiveJobStatus
.app, .app__primary, .app__logThe page grid: one column, then two with the log on the right (L2-064 to L2-066).Shipped
.stackVertical rhythm between siblings.Shipped
.clusterA wrapping row of inline items (buttons, meta).Shipped
.containerCentred max-width wrapper with page margins.Shipped (kit), unused by the page
body.has-stop-barReserves room for the fixed Stop bar while the belt is active.Shipped

Anatomy

  1. Primary column.app__primary: intro, status, connection, telemetry, belt controls, 16 px apart.
  2. Log column.app__log: the packet log panel; below the primary column under 992 px, to the right from 992 px.
  3. Page padding24 px top, --layout-margin sides, 48 px bottom.
  4. Cap720 px content below 992 px; 1140 px content from 992 px (XL).

States

Layout primitives have no interactive states. The page layout has one state switch: the Stop bar.

Responsive behaviour

  • Below 768 px: one column, 16 px margins, in the L2-064 order status → connection → telemetry → belt → log, no horizontal scroll at 320 px.
  • 768 px to 991 px: one column capped at 720 px and centred (L2-065).
  • 992 px and up: two equal columns with a 24 px gutter; the log column is sticky under the top bar and fills the viewport height (L2-066).
  • 1200 px and up: content capped at 1140 px.
  • Zoom to 200 % reflows to the one-column layout; nothing is fixed-width except the Stop bar's button (L2-067).

Theming

Layout primitives draw nothing and read no colour tokens; only spacing and layout tokens. They behave the same in both themes.

Accessibility

Role and pattern

.app is the <main> landmark (id main). Visual order equals DOM order at every breakpoint (the log is last in the DOM and placed right by the grid), so reading and focus order never diverge (WCAG 1.3.2, 2.4.3).

Keyboard

KeyAction
TabMoves through the primary column, then the log; never reordered by CSS.

Focus

The sticky log column and the fixed Stop bar must not hide a focused control: has-stop-bar padding keeps the last control scrollable above the bar (WCAG 2.4.11).

Labelling

Primitives add no names.

Contrast

Not applicable: primitives draw no colour.

Motion

None.

Touch

Gaps keep adjacent 44 px targets at least 12 px apart (.cluster).

Content

Not applicable: layout primitives carry no copy.
