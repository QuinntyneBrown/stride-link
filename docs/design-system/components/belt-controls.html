Belt controls

The interlocked controls that can move the belt: safety list, the standing-clear gate, Start, speed and incline.

Overview

Belt controls are the only part of Stride Link that can move the belt, so they sit behind an interlock. The panel appears only under a Talks or Unlocked verdict (L2-042). It shows the safety list and one checkbox, I am standing clear of the belt. Start, speed and incline are not rendered or focusable until the tester ticks it.

  • Gate closed: safety list and the unticked checkbox only. Start, speed and incline are hidden, so they leave layout, the accessibility tree and the Tab order (shipped [hidden] rule).
  • Gate open: Start, then speed (0.0 to 3.0 km/h, steps of 0.1) and incline (whole numbers 0 to 15), each applied by its own button (L2-043, L2-046, L2-047).
  • Stopping is never here: Stop belt is a fixed bar that stays on screen while the belt is active, even when the gate is unticked (L2-042 acceptance 6, L2-045).

Interlock rules (AGENTS.md): never weaken the standing-clear gate, the 3 km/h cap, Stop jumping the write queue, Stop always on screen, or Escape sending Stop. A change to this component needs a test proving each still holds.

Responsive behaviour

  • Below 576 px everything is one column: Start, then speed, then incline.
  • From 576 px speed and incline sit side by side (repeat(2, minmax(0, 1fr))) and Start spans both columns.
  • The panel is fourth in the single-column order (L2-064) and stays in the left column from 992 px (L2-066).
  • While the Stop bar is shown, the body reserves its height plus --space-2 (shipped), so the incline field is never hidden behind the bar (L2-064 acceptance 2).

Theming

The gate box is --color-bg-surface-raised with a --color-border-strong edge so it stands out from the panel in both themes; the ticked box fills with --color-accent and an ink check (--color-fg-on-accent).

Accessibility

Role and pattern

A native checkbox wrapped in its <label> (WAI-ARIA Checkbox pattern, no ARIA), and two form fields. Hidden controls use the hidden attribute, so they are absent from the accessibility tree and cannot be reached by Tab (L2-042 acceptance 2). Field errors are role="alert" paragraphs referenced by aria-describedby.

Keyboard

KeyAction
TabGate checkbox, then (when ticked) Start, speed input, Set speed, incline input, Set incline, in visual order (L2-060).
SpaceTicks or unticks the gate.
Enter, Space on a buttonStart, or apply the typed value.
↑ ↓ in an inputStep by 0.1 km/h or 1 incline level (native number input).
Esc, anywhereWhile the belt is active, sends Stop, even from inside an input (L2-045 acceptance 4).

Focus

Ticking the gate keeps focus on the checkbox; the new controls follow it in Tab order. The gate can only be unticked from the checkbox itself, so focus is already there when the controls disappear and is never lost in hidden content.

Labelling

The checkbox name is exactly I am standing clear of the belt (L2-042). Inputs are named by their visible labels, Target speed (km/h) and Target incline; buttons by their text (L2-063).

Motion

Box fill transitions over 120 ms; removed under reduced motion.

Touch

The checkbox itself is 44 × 44 px (shipped) and the whole label row is clickable; every button and input is at least 44 px tall (L2-061).

Content

  • Gate label: I am standing clear of the belt (L2-042), no full stop.
  • Safety list (shipped): “Keep the treadmill's safety key within reach.” and “Speed is capped at 3 km/h.”
  • Errors are fixed by L2-046 and L2-047: Speed is capped at 3 km/h for the smoke test., Enter a speed from 0 to 3 km/h., Enter a whole-number incline from 0 to 15.
  • Buttons: Start, Set speed, Set incline (shipped, set B). Set A uses Start belt and two Apply buttons.
