Component · Data display

Telemetry

Three readouts, speed, incline and heart rate, showing the last decoded value or a dash. Never announced, never cleared for staleness.

Overview

Telemetry shows the last decoded speed, incline and heart rate, each with its unit, or a dash before the first value (L2-032). Values are never cleared for staleness, because the treadmill sends speed and incline only when they change; they reset to the dash when a new run starts.

  • Telemetry is deliberately not a live region: updates are not announced (L2-063).
  • It always shows three readouts in a fixed order: Speed, Incline, Heart rate.

Anatomy

  1. Labeldt.metric__label: --text-label, muted.
  2. Valuedd.metric__value: Inter Tight bold, 24 px (30 px from 576 px), tabular numbers, tight tracking.
  3. Unitspan.metric__unit: 16 px medium, muted, after a real space.

Variants

Two variants of a readout: a value with a unit (speed, heart rate), and a unitless value (incline). The empty state is a modifier.

Sizes

One size, two layouts (see responsive behaviour). The value is 24 px in the stacked phone layout and 30 px (--font-size-3xl) in the three-column layout.

Responsive behaviour

  • Below 576 px each readout is a row: label left, value right (justify-content: space-between), 8 px apart.
  • From 576 px (--layout-breakpoint-sm) the three readouts sit in one row of three columns, label above value (L2-064 acceptance 3).
  • From 992 px the telemetry panel stays in the left column with status and controls (L2-066).
  • Values never wrap; the 30 px value fits “3.00 km/h” at the narrowest three-column width.

Theming

One component token, --metric-bg, defaults to --color-bg-surface-sunken: the well reads as recessed inside the panel in both themes (paper-200 in light, ink-950 in dark).

Accessibility

Role and pattern

A description list: <dl> with each <dt>/<dd> pair wrapped in a <div> (valid HTML). Screen readers announce “Speed, 1.50 km/h”. No aria-live (L2-063).

Keyboard

KeyAction
NoneReadouts are not focusable; screen-reader users read them with the virtual cursor.

Focus

Never receives focus.

Labelling

The visible dt labels the value. Keep a real space between value and unit so it is read as two words. Set A instead hides the dash and adds visually hidden “No reading yet”; the shipped page reads the dash itself (“em dash” or silence, depending on the reader). Both are acceptable; the shipped form is simpler.

Motion

None: values change in place without animation.

Touch

Not a target.

Content

  • Labels: Speed, Incline, Heart rate, sentence case.
  • Units: km/h and bpm, lower case, after a space. Incline has no unit (the treadmill reports a level, not a percentage).
  • Speed always has two decimals (0.00, 3.00), so the column does not jump.
  • The empty value is an em dash —, never “0”, “N/A” or blank: zero is a real reading.
