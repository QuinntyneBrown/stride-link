Top bar

The sticky page header: brand lockup and privacy pill, nothing to navigate.

Overview

The top bar is the page's <header>: the brand lockup on the left and the privacy pill on the right. It has no navigation, search, menu or actions, because Stride Link is one page with nothing to navigate to. It sticks to the top of the viewport so the offline promise is always visible.

  • Shipped, set A and set B all use the same two parts; they differ only in the brand element and the pill copy.
  • The page title (Treadmill smoke test) is not in the bar; it is the <h1> inside the status panel.
  • Never put controls in the bar: Stop lives in the fixed Stop bar at the bottom, which is where a thumb reaches.

Anatomy

  1. Brand lockup.brand, 20 px wordmark, role="img" named Stride Link (shipped).
  2. Spacer.topbar__spacer pushes the pill to the end.
  3. Privacy pill.privacy-pill; the long text appears from 576 px.
  4. Container60 px minimum (--layout-topbar-height), canvas background, 1px bottom rule, sticky at --z-sticky.

Sizes

One size: 60 px minimum height with --layout-margin side padding (16 px below 768 px, 32 px from 768 px). The bar grows only if the pill wraps, which it does not at 320 px because the long text is hidden below 576 px.

States

The bar itself has no interactive states. In set B the brand is a link and gets the link focus state; in the shipped page and set A nothing in the bar is focusable.

Sticky behaviour cannot be shown statically: the bar stays at the top while the page scrolls under it at every breakpoint.

Responsive behaviour

  • Below 576 px the pill shows only Offline; from 576 px it adds · nothing leaves this device.
  • Side padding follows --layout-margin: 16 px, then 32 px from 768 px.
  • The bar spans the full viewport at every width; the content below it is capped at 720 px (768 px+) and 1140 px (992 px+).
  • At 992 px and up the sticky log column starts below the bar (top: calc(var(--layout-topbar-height) + var(--space-4))).

Theming

The bar uses --color-bg-canvas (not surface) so it reads as part of the page, with a --color-border-default rule. In dark it is ink-900 with an ink-650 rule; the brand mark's outline follows the text colour and its arcs stay signal orange.

Accessibility

Role and pattern

A <header> landmark (banner). No <nav>, because there are no links to group.

Keyboard

KeyAction
TabShipped and set A: nothing in the bar takes focus, so the first stop is in the main content. Set B: the brand link is the first stop after the skip link.

Focus

Because the bar is sticky, scrolled content must never sit under it while focused: the shipped page has no focusable content that scrolls behind the 60 px bar without the browser scrolling it into view.

Labelling

The brand is announced once as Stride Link (role="img" with aria-label; the wordmark is aria-hidden). The pill is plain text.

Motion

None.

Content

  • The bar carries only the product name and the privacy promise; no version, no status.
  • Pill copy: shipped and set A say Offline · nothing leaves this device; set B says Local only · nothing leaves this device. The system follows the shipped wording.
