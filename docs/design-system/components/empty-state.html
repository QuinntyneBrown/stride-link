Empty state

What a region shows before it has content: a short line naming what will appear and what to press.

Overview

An empty state is what a region shows before it has content. Stride Link has no empty-state illustration or page. Its empty states are short, specific lines inside the region that will fill. Each one says what will appear and, where the tester can do something, what to press.

RegionEmpty stateSource
Packet log“No entries yet. Press Connect to start a run.” centred in the well; Export log disabledshipped, set B (set A wording differs)
Telemetryan em dash — per readoutshipped, both sets; see Telemetry
Verdictnothing (card hidden)shipped; set B shows “No verdict yet.”, set A a waiting card
Browser chooser“No compatible devices found.”both sets, browser-owned

Anatomy

  1. ContainerThe region that will fill (here the log well), at its normal size, so the layout does not jump when content arrives.
  2. Message.log__empty: centred, --text-body-sm, muted, 32 px block padding. One or two short sentences.

Sizes

No sizes of its own: an empty state takes the size of the region it stands in.

States

Empty states are not interactive. The log well around the message stays focusable, so its focus state applies.

Responsive behaviour

  • The message wraps and stays centred at every width.
  • Below 992 px the empty log well keeps its normal height (up to 26rem), so the log panel does not collapse.

Theming

Messages read --color-fg-muted on the region's own surface; the set B placeholder uses --color-bg-surface-sunken with a dashed --color-border-strong edge. No dark-specific rules.

Accessibility

Role and pattern

Plain text inside the region; it takes the region's role (the log's empty message is inside role="log", which has aria-live="off"). It is not announced when it appears or disappears.

Keyboard

KeyAction
TabThe empty log well is still focusable so its position in the Tab order does not change when entries arrive.

Focus

Never moved to the message.

Labelling

The message is read as part of the region. The em dash in telemetry may be read as “em dash” or skipped, depending on the reader. Either way, the label says which reading is missing.

Content

  • Say what will appear, then what to do: “No entries yet. Press Connect to start a run.”
  • Name the control exactly as its label reads (Connect).
  • No illustrations, no jokes, no exclamation marks.
