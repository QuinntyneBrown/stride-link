Progress bar

A bounded wait shown as a filling track, used by set A for init frames and the reply and acknowledgement windows.

Overview

A progress bar shows how far through a known, bounded wait the run is. Only set A uses one, inside a waiting card where the verdict will appear. It tracks three things: frames of the init sequence, the 20-second wait for any reply (L2-033), and the 2.5-second wait for the unlock acknowledgement (L2-024). The shipped page and set B show no progress. The status line says what is happening, and the log shows each frame.

  • Use it only when both ends are known: a frame count or a fixed timeout.
  • Use a spinner for a wait with no known end (the browser's chooser scan).
  • Never use it for a belt command: belt frames are fire-and-log, with no progress to show.

Anatomy

  1. Label.verdict__label overline, also the bar's accessible name.
  2. Track.progress: 8 px pill in --progress-track.
  3. Fill.progress__bar: width from --value, colour --progress-fill (--color-accent-border).
  4. Meta.verdict-wait__meta: numeric progress (left) and context (right), muted, tabular numbers.

Responsive behaviour

  • The bar fills its container at every width.
  • The meta line wraps: the right-hand context drops under the left-hand count on narrow screens (flex-wrap).

Theming

Two component tokens: --progress-track (--color-bg-subtle-hover) and --progress-fill (--color-accent-border). The fill uses the accent border, not --color-accent, because the accent fails 3:1 against the light track.

Accessibility

Role and pattern

The WAI-ARIA progressbar role with aria-valuemin, aria-valuemax and aria-valuenow in the bar's real units (frames or seconds), plus an aria-label matching the visible label. Add aria-valuetext (“12.4 s of 20 s”) so screen readers do not read a bare percentage.

Keyboard

KeyAction
NoneNot focusable.

Focus

Never receives focus.

Labelling

Set A also puts aria-live="polite" on the waiting card, so every tick of the meta would be announced. Do not do that: announce the phase change through the status line and leave the bar silent.

Contrast

Meta text on card--color-fg-muted on --color-bg-surface-sunken
Fill on track--color-accent-border on --color-bg-subtle-hover
Meta text on card--color-fg-muted on --color-bg-surface-sunken

The track is decorative and only marks the full length; the fill carries the information at 3:1 or more, and the meta carries it in words.

Motion

The fill animates width over --duration-slow; removed under reduced motion.

Touch

Not a target.

Content

  • Label: what is being waited for, in sentence case (“Waiting for any reply”).
  • Meta: count first (“Frame 2 of 6”, “12.4 s of 20 s”), then context (“Keepalive every 2 s”, “Attempt 1”).
  • Seconds use one decimal for the short waits, with a space before the unit: “2.5 s”.
