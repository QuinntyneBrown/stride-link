Packet log

Every frame and event of the run, in the L2-038 line format, live in a role=log scroller and exportable as a file.

Overview

The packet log shows every frame written to f2 (TX), every notification from f3 or f4 (RX) and every protocol event (EV), in order, live (L2-037, L2-039). It is the evidence behind the verdict, and Export log saves it as a file (L2-040).

  • Lines use one fixed, diff-friendly format: <ms> <DIR> <char> <hex> <tag>, milliseconds right-aligned to 10 characters with one decimal (L2-038).
  • The DOM holds the latest 500 entries; the full log stays in memory for export (L2-039).
  • It follows new entries while the tester is at the bottom and keeps the scroll position when they have scrolled up (L2-039 acceptance 3).
  • From 992 px it is the right-hand column and scrolls on its own (L2-066).

Shipped: each line is a single text node produced by formatEntry(), so the log__line--tx, --rx, --ev and --error modifiers it sets have no visual effect: every shipped line, error lines included, is --color-fg-default on the well, and a failed write is identified by its words (write failed and the error name, L2-019). The mocks split each line into spans (log__t, log__dir, log__hex, log__tag, log__text) to colour the direction. The shipped scroller is flex-direction: column (oldest first, newest at the bottom, the view scrolls itself); the mocks used column-reverse.

Anatomy

  1. HeaderPanel title “Packet log” and the entry count caption (tabular numbers).
  2. Legend (mocks)TX / RX / EV key. Set B puts it above the log, set A below; not shipped.
  3. Run headingli.log__run: overline style, “Run 1 · STRIDE-8S”. Shipped also uses “Page events” before the first run.
  4. Scrollerdiv.log role="log", sunken well, 26rem tall below 992 px, full column height above.
  5. Lineli.log__line, JetBrains Mono 12 px (14 px from 576 px), line height 1.6, wrapping between bytes.
  6. Export logSecondary button; disabled until the log has an entry.

Responsive behaviour

  • Below 992 px the log panel is last in the single column (L2-064 order) and its scroller is at most 26rem tall, so the page does not become one long log.
  • From 992 px it is the right-hand column: sticky under the top bar and as tall as the viewport, with its own scroll (L2-066 acceptance 3). While the Stop bar is shown its height is reduced by the bar.
  • Long hex lines wrap inside the scroller (white-space: pre-wrap; overflow-wrap: anywhere) and never scroll the page (L2-064 acceptance 4). Shipped wrapped lines hang by 1ch; the mocks hung them by 11ch to line up under the direction column.

Theming

The well is --color-bg-surface-sunken; mock line colours read --color-fg-accent (TX), --color-success-fg (RX), --color-fg-muted (EV), --color-fg-subtle (timestamps) and --color-danger-fg (errors). All have dark values; no log-specific dark rules exist.

Accessibility

Role and pattern

The WAI-ARIA log role with the accessible name Packet log (L2-039 acceptance 4). Shipped sets aria-live="off" on top of the role so hundreds of frames a minute are not read aloud; the status line and verdict carry the announcements.

Keyboard

KeyAction
TabFocuses the scroller (after the controls in the left column).
↑ ↓ PgUp PgDn Home EndScroll the log. Scrolling up pauses following; End resumes it.
Tab againMoves on to Export log.

Focus

The shared ring sits outside the well, on the panel surface (3:1 or more). The ring is visible on :focus-visible only.

Labelling

aria-label="Packet log" on the scroller; the visible panel title says the same. Device names inside lines are inserted as text, never HTML (L2-051): a hostile name such as <img src=x onerror=alert(1)> renders literally.

Motion

No animation; following new entries jumps (it does not smooth-scroll), so reduced motion needs no special case.

Touch

The well scrolls with one finger; overscroll-behavior: contain stops the page from scrolling when the log reaches its end. Export log is 44 px tall.

Content

  • Hex is upper-case two-digit bytes separated by single spaces: F0 A4 00 94 (L2-016).
  • Tags are lower case: init, unlock response, activation, keepalive, echo, belt (L2-037).
  • Event text uses L2's words: Connected, Service found, Init complete, Challenge …, Unlock attempt 2, Acknowledged, Verdict: unlocked, Verdict changed: talks -> unlocked, Belt start requested, Belt stop requested, Disconnected.
  • The count caption is “0 entries”, “1 entry”, “2,000 entries” (thousands separator, singular for one).
