Stop bar

The fixed bar that holds Stop belt: 64 px, always on screen while the belt may move, first in the write queue, bound to Escape.

Overview

The Stop bar holds Stop belt, the one control that must always work. It is fixed to the bottom of the viewport from the first belt command until the belt is stopped or the link drops (L2-045). It stays on screen when the belt-controls gate is unticked, at every width and zoom level. Stop is written ahead of any queued frame, and Esc anywhere on the page sends it (L2-044).

  • Stop belt is never disabled, never busy and never hidden while the belt may be moving.
  • If the Stop write fails, the bar shows Stop failed. Use the treadmill's stop button or safety key now. as an alert, and Stop stays pressable so the tester can try again (L2-044 acceptance 4).
  • For starting and adjusting the belt, see Belt controls.

Interlock (AGENTS.md): Stop jumps the write queue, Stop is always on screen, and Escape sends Stop. Never weaken these; a change here needs a test proving each still holds.

Anatomy

  1. BarFixed, full width, --color-bg-canvas with a top hairline and --shadow-3, above everything except dialogs (--z-stop-bar).
  2. Stop beltDanger button, at least 64 × 64 px (--target-stop), 20 px extrabold label, filled square stop icon.
  3. Shortcut hint<kbd aria-hidden="true">Esc</kbd>; the shortcut is exposed by aria-keyshortcuts="Escape".
  4. Meta (mocks).stop-bar__meta: belt state and last reported speed, hidden below 768 px. Not shipped.

Sizes

One size. The button is at least 64 px tall and wide (L2-061). Below 768 px it fills the bar; from 768 px it is up to 24rem wide and the meta (mocks) sits beside it. The bar reserves --layout-stop-bar-height (5rem) at the bottom of the page.

The Stop belt button has default, hover, focus and active states. It is never disabled and never loading.

Responsive behaviour

  • Fixed to the bottom at every width; the button is fully inside the viewport at 320 px and at 200 % zoom (L2-045 acceptance 2, 3).
  • body.has-stop-bar adds padding-bottom: calc(var(--layout-stop-bar-height) + var(--space-2)) (shipped; the mocks had no extra space), so the last field and the footer scroll clear of the bar.
  • From 992 px the log column's height subtracts the bar so the log's end stays visible.
  • While the bar is shown, toasts rise above it: body.has-stop-bar .toast-region sets bottom to the bar height plus --space-4 (system fix; see the do/don't below).
  • Below 768 px the meta is hidden and the button fills the row; from 768 px the button is capped at 24rem.
  • The bar is hidden when printing.

Theming

The button uses the danger button tokens (--btn-danger-bg, --btn-danger-fg); the bar uses --color-bg-canvas and --color-border-default. The kbd hint reads --color-fg-default on its own --color-bg-subtle chip, so it stays legible on the red button in both themes.

Accessibility

Role and pattern

A role="region" landmark named Belt stop, holding one native button. The stop-failed text is role="alert": an assertive announcement is right for the one message that means the tester must act physically now.

Keyboard

KeyAction
Esc, anywhereSends Stop while the belt is active, even with focus in an input. Handled in the capture phase, so no other handler can swallow it (L2-044, L2-045 acceptance 4).
TabReaches Stop belt as the last control in the page order (it is last in the DOM).
Enter, SpaceSends Stop.

Focus

Showing the bar never moves focus. Esc does not move focus either. After a stop failure, focus stays where it was, and Esc or the button retries.

Labelling

The accessible name is the visible text, “Stop belt”. The Esc hint is aria-hidden so the name is not “Stop belt Esc”; aria-keyshortcuts="Escape" exposes the shortcut. Set A adds a redundant aria-label="Stop belt" and leaves the kbd exposed.

Motion

The bar appears without animation; there is nothing to reduce.

Touch

At least 64 × 64 px (--target-stop), full width on phones, with nothing overlapping it.

Content

  • Button: Stop belt. Not “Stop”, “Emergency stop” or “Pause”. Stride Link's Stop is a protocol frame, not a safety stop; the treadmill's own stop button and safety key are.
  • Failure: Stop failed. Use the treadmill's stop button or safety key now. (L2-044), verbatim.
  • Meta (mocks): “Belt active · 1.50 km/h”, middle dots between facts.
