Toast

A short message in the page corner after an action. Set A only; never the only home of an L2 message, and never over Stop belt.

Overview

A toast is a short message that appears over the page corner after an action and goes away on its own or when dismissed. Only set A uses toasts: for belt commands, log export and verdict changes. The shipped page has none, because every outcome toasts would carry already lives somewhere persistent: the status line, the verdict or the packet log. This page documents toasts so set A can be built consistently if the owner chooses it.

  • Use a toast for a confirmation the tester can safely miss (Log exported).
  • Never put the only copy of an L2 message, a safety instruction or a verdict in a toast: toasts vanish.
  • Never auto-dismiss a toast that has an action, and never let a toast cover Stop belt.

Status: mocks only (set A). The system CSS fixes two set A defects: toasts rise above the Stop bar (body.has-stop-bar .toast-region) and the action is 44 px tall.

Anatomy

  1. Icon20 px, --toast-icon (the status -icon-on-inverse tokens), aria-hidden.
  2. Title--text-label.
  3. Text--text-body-sm at 90 % opacity.
  4. Action (optional)Underlined text button, 44 px tall (system fix).
  5. Dismiss44 × 44 px icon button, aria-label="Dismiss".
  6. Surface--color-bg-inverse with --color-fg-inverse text and --shadow-3, in both themes.

Responsive behaviour

  • Below 640 px the region spans the width with 16 px side margins; from 640 px it is 24rem wide at the bottom right.
  • While the Stop bar is shown, the region sits above it (bottom: calc(var(--layout-stop-bar-height) + var(--space-4))). Without that rule, set A's belt toasts cover Stop belt at 360 px.
  • The region ignores pointer events; each toast re-enables them, so the page under the gaps stays clickable.
  • Hidden when printing.

Theming

The toast surface is the inverse pair in both themes (ink on light, paper on dark), so it reads as an overlay. Icon colours use the -icon-on-inverse tokens, because the ordinary -icon tokens fail 3:1 on the inverse surface.

.toast--warning { --toast-icon: var(--color-warning-icon-on-inverse); }

Accessibility

Role and pattern

The region is a polite live region (role="status" aria-live="polite"), so toasts are announced without moving focus. Set A also puts role="alert" on danger toasts, which nests an assertive region inside a polite one; screen readers handle that inconsistently. Use one region and no per-toast role.

Keyboard

KeyAction
TabReaches the action and Dismiss in DOM order (the region is last in the page).
Enter, SpaceRuns the action or dismisses.
EscNot used for toasts: Esc is reserved for Stop while the belt is active.

Focus

A toast never takes focus. After Dismiss, focus returns to the element focused before the tester tabbed into the toast, or to the next toast.

Labelling

The Dismiss button is icon-only, so it carries aria-label="Dismiss". The title and text are the message.

Timing

WCAG 2.2.1: a toast with an action must not auto-dismiss. Set A's warning toasts “Log not exported yet” and “Verdict changed: Talks → Locked” have both an action and a progress bar; that is drift.

The icons are the thinnest margins on this page, at about 3.6:1. Do not lighten the surface.

Motion

slide-up and fade-out are removed under prefers-reduced-motion: reduce; toasts appear and disappear instantly.

Touch

Dismiss is 44 × 44 px and the action is at least 44 px tall (set A's action was about 29 px, which fails L2-061).

Content

  • Title: what happened, sentence case, no full stop (“Log exported”).
  • Text: one or two sentences, with numbers and file names where they help.
  • Action: a verb, such as Try again or Export log.
  • Set A toast copy is mock copy; L2 fixes none of it. If a toast repeats an L2 message, it must match L2 character for character.
