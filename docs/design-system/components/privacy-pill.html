Privacy pill

A static label in the top bar: Offline · nothing leaves this device.

Overview

The privacy pill states the product's promise in the top bar: the page works offline and nothing it sees leaves the device (L2-049 no network, L2-052 no persistence). It is a static label, not a button and not a status.

  • Always present, in every state, because the promise never changes.
  • Short form Offline below 576 px; long form Offline · nothing leaves this device from 576 px.

Anatomy

  1. Icon (mocks only)16 px lock, aria-hidden. The shipped pill has no icon.
  2. Short textAlways shown.
  3. Long text.privacy-pill__long, hidden below 576 px.
  4. Container32 px tall, full radius, 1px --color-border-default outline, label font, muted text.

Sizes

One size: min-height: var(--space-8) (32 px), --space-3 side padding, --text-label. It is not interactive, so the 44 px target rule does not apply.

States

Not interactive: no hover, focus, active or disabled states. Its only variation is responsive.

Responsive behaviour

  • Below 576 px (--layout-breakpoint-sm) only the short text shows, so the top bar fits at 320 px.
  • From 576 px the long text appears inline. It never wraps (white-space: nowrap).

Theming

Reads --color-fg-muted for text and --color-border-default for the outline; the outline is decorative (the text carries the meaning). Dark: paper-400 text on ink-900 with an ink-650 outline.

Accessibility

Role and pattern

Plain inline text inside the banner landmark. No live region: it never changes.

Keyboard

KeyAction
NoneNot focusable.

Focus

Not focusable.

Labelling

Screen readers read the visible text. The long part is hidden with display: none below 576 px, so it is not read there either; the short text alone is complete.

Motion

None.

Touch

Not interactive; it must never look tappable (no hover, no pointer cursor).

Content

  • Shipped wording: Offline and · nothing leaves this device. Set A matches; set B says Local only.
  • Lower case after the middle dot; no full stop.
  • Do not add claims the product does not test, such as “secure” or “private”.
