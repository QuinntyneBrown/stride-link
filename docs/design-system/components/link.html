Link

Links go somewhere: on this page, only to the hosted HTTPS copy when Bluetooth is blocked on a file opened from disk.

Overview

A link takes the tester somewhere else. Stride Link is one offline page, so it has exactly one destination worth a link: the hosted HTTPS copy, offered when the browser blocks Bluetooth on a file opened from disk (L2-004). Everything that changes state on the page is a button.

  • Inline link: underlined text in the signal-700 link colour, inside a sentence or an alert's action row.
  • Link button (a.btn.btn--link): the shipped hosted-copy link. It keeps link semantics but gets a 44 px button-sized target (L2-061).
  • Inherited link: inside an alert or the footer a link takes the surrounding text colour (color: inherit) and keeps its underline.

The hosted URL is set at build time (L2-004). This system never prints a real URL in examples; the mocks print one, which is listed under drift.

Anatomy

  1. Link textSays where it goes; the accessible name. Signal-700 in light, signal-300 in dark.
  2. Underline1 px at 0.15em offset; 2 px on hover. Always present, so the link never relies on colour alone (1.4.1).

Variants

Choose the link button when the link is the main way out of the current state; choose an inline link when it sits inside text.

Sizes

Links have no size modifiers. An inline link takes the size of its text. The link button is 44 px tall (--control-height-md) to meet the L2-061 target floor; an inline link that is the only action in a state must use the link button instead, because inline text cannot guarantee 44 × 44 px.

States

Hover, focus and active are forced with data-state. Links have no disabled state: if the destination is unavailable, the link is not rendered (the shipped page hides #hosted-link-row outside the blocked state).

Visited is not styled: the only destination is the same page hosted elsewhere, so a visited colour would carry no information.

Responsive behaviour

  • Links wrap with their sentence. A long URL inside an alert action row breaks anywhere (overflow-wrap: anywhere on .alert__actions a), so it never forces horizontal page scroll at 320 px (L2-064).
  • The link button stays its natural width at every breakpoint; it never becomes full width.

Theming

Links read --color-fg-link and --color-fg-link-hover. Light uses signal-700 and signal-800 (orange text needs the dark steps to reach 4.5:1 on paper); dark uses signal-300 and signal-200. The link button adds --color-accent-subtle as its hover wash through --btn-bg-hover.

a { color: var(--color-fg-link); text-decoration: underline; text-underline-offset: 0.15em; }
.btn--link { --btn-fg: var(--color-fg-link); --btn-bg-hover: var(--color-accent-subtle); }

Accessibility

Role and pattern

Native <a href>, following the WAI-ARIA Authoring Practices Link pattern with no ARIA. The link button is still an anchor: it navigates and announces as a link.

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the link in reading order (L2-060).
EnterFollows the link. Space scrolls the page, as for every link.

Focus

The shared 2 px ring with a 2 px offset on :focus-visible; inside an alert the ring sits on the alert's tint and stays at least 3:1.

Labelling

The link text is the name and must make sense alone: Open the hosted copy, never a bare URL or “here”. L2-004 fixes the sentence before it; the link text itself is shipped wording.

Motion

Only the link button transitions its background (120 ms); removed under reduced motion.

Touch

The link button is 44 px tall (L2-061). Inline links inside alerts are secondary to the alert text and are never the only way to complete a step on a touch device.

Content

  • Link text starts with a verb and names the destination: Open the hosted copy.
  • The sentence before it is fixed by L2-004: This browser blocks Bluetooth on files opened from disk. Open the hosted copy instead. The link follows that sentence (L2-004 criterion 3).
  • Never print the hosted URL as the link text: it is long, set at build time, and reads poorly to a screen reader.
  • Footer and alert links inherit the surrounding colour; do not recolour them.
