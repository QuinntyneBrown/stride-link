Skip link

Skip to content: in both mock sets; the shipped page omits it because nothing focusable precedes the main content.

Overview

The skip link is the first focusable element on the page and jumps to #main. It stays off screen until it receives keyboard focus.

  • Both mock sets start every page with Skip to content.
  • The shipped page has no skip link. Its top bar contains nothing focusable, so the first Tab already lands in the main content and there is no repeated block to bypass; the <main> landmark (id main) landmark satisfies WCAG 2.4.1 for screen-reader users.
  • Add the skip link back if anything focusable is ever added to the top bar. The documentation site itself uses one because its sidebar is long.

Anatomy

  1. LinkRaised surface, --radius-md, --shadow-3, 8 × 16 px padding, default text colour, no underline.
  2. PositionAbsolutely positioned 96 px above the viewport; slides to 16 px from the top on :focus-visible.

Responsive behaviour

Identical at every width: 16 px from the left and top edges when focused, above the sticky top bar (--z-tooltip).

Theming

Reads --color-bg-surface-raised, --color-fg-default and --shadow-3; in dark the raised surface is ink-800 with a deeper shadow.
