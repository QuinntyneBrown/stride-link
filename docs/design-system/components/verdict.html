Verdict

The answer to the run: one of four words with its meaning, reason, next step and Export log, announced politely.

Overview

The verdict card is the answer the whole page exists to give. Every run ends in exactly one of four words, Silent, Talks, Unlocked or Locked, shown with its meaning, its reason where one exists, its next step, and an Export log button (L2-036). The card sits under the status line in the first panel and is announced through its own polite live region.

  • Tone follows the outcome: Silent is danger, Talks and Unlocked are success, Locked is warning. The word, not the colour, carries the meaning (L2-062).
  • Before a verdict exists nothing is shown in the shipped page (L2-033). Set B shows a dashed No verdict yet. placeholder; set A shows a waiting card with a 20-second progress bar.
  • A verdict can change within a run (for example Talks → Unlocked, L2-025, L2-034); the card updates in place and is announced again.

Anatomy

  1. Icon disc (mocks)48 px disc in --color-bg-surface with a 24 px outcome icon in --verdict-icon. Not shipped.
  2. Label“Verdict” in --text-overline, muted. Set A appends “· Run 1”.
  3. Word--text-display: 48 px Inter Tight 800, wordmark tracking, in --verdict-word. A heading (h2 shipped).
  4. Factsdl.verdict__facts: Meaning, Reason (mono, only when one exists), Next step.
  5. Export logSecondary button, always present with a verdict (L2-036 acceptance 5).
  6. Accent bar4 px left border (--border-width-accent) in --verdict-bar on a --verdict-bg tint.

Variants

Four outcomes, each with fixed L2 copy. These are the shipped cards: no icon, word as h2.

Responsive behaviour

  • Below 576 px the facts stack: term above value, with --space-2 before each new term.
  • From 576 px the facts are a two-column grid (max-content terms, flexible values).
  • The word never wraps (one short word at 48 px fits a 320 px viewport inside the panel padding).
  • The Export log button grows to the row width below 576 px, as all .panel__actions buttons do.

Theming

Four component tokens, set per outcome: --verdict-bg, --verdict-bar, --verdict-icon, --verdict-word. They alias the status -bg, -solid, -icon and -fg tokens, so the dark theme needs no verdict rules: deep tints with light words.

.verdict--locked { --verdict-bg: var(--color-warning-bg); --verdict-bar: var(--color-warning-solid); --verdict-icon: var(--color-warning-icon); --verdict-word: var(--color-warning-fg); }

Accessibility

Role and pattern

The card lives in #verdict-region, a div aria-live="polite" aria-atomic="true", so a new or changed verdict is read in full once (L2-036 acceptance 6). The word is a heading (h2 shipped; set B uses h3, set A a paragraph), so screen-reader users can jump to it. The facts are a <dl>.

Keyboard

KeyAction
TabReaches Export log inside the card, in reading order after the status line.
Enter, SpaceExports the log (L2-040).

Focus

A verdict never moves focus; it is announced instead. After a verdict, the next Tab from the top of the panel lands on Export log.

Labelling

Each fact has a visible term (Meaning, Reason, Next step). The icon in the mocks is decorative (aria-hidden). In greyscale the word, meaning and next step remain (L2-062 acceptance 1).
