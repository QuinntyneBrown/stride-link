Inline message

One-line help, error and status text attached to the control or region it describes.

Overview

Inline messages are one-line texts attached to the thing they describe. They never float and never time out.

  • Field help (.field__help): the accepted range under a field. Always visible. Shipped.
  • Field error (.field__error): the L2 message after an invalid apply, with a ⚠ prefix so it is not colour alone. Shipped.
  • Inline status (.inline-status): a short muted status with a leading spinner or dot. Mocks only: set A uses it for the chooser's scanning line; set B draws the same line as .chooser__scan.

For page-level state use the status line; for problems that need reading use an alert.

Anatomy

  1. Help textBody-sm, --color-fg-muted.
  2. Error marker⚠ generated by ::before; text-equivalent signal besides colour.
  3. Error textBody-sm, --color-danger-fg; the L2 wording.

Sizes

One size: --text-body-sm (14 px). The 16 px body floor of L2-067 applies to base body text; secondary lines may be 14 px and still meet contrast.

States

Inline messages are static text; they have no interactive states. Their only states are shown and hidden.

Responsive behaviour

Messages wrap within their container at every width and never truncate; at 320 px a field error may take two lines.

Theming

Help reads --color-fg-muted, error --color-danger-fg, inline status --color-fg-muted or the success and danger foregrounds. The spinner uses --color-border-default and --color-accent.

Accessibility

Role and pattern

Help and error are plain paragraphs referenced by the field's aria-describedby. The shipped field error also carries role="alert", so it is announced when it appears. The chooser's inline status belongs to the browser, so its semantics are the browser's.

Keyboard

KeyAction
NoneInline messages are not focusable.

Focus

Not focusable; focus stays on the control that produced the message.

Labelling

The spinner and dot are aria-hidden; the words carry the meaning.

Motion

The spinner rotates; under reduced motion the shipped rule stops it (it becomes a static ring) and the words remain.

Touch

Nothing to tap.

Content

  • Errors are the L2 strings verbatim: Speed is capped at 3 km/h for the smoke test., Enter a speed from 0 to 3 km/h., Enter a whole-number incline from 0 to 15.
  • Help states the rule, not an instruction: Whole numbers from 0 to 15.
  • Inline status is a fragment with an ellipsis while ongoing: Scanning for devices…
