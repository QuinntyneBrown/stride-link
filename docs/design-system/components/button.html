Button

Buttons start actions: connect, export, start and stop the belt. One primary per state; Stop belt is the only danger button.

Overview

A button starts an action on this page: connect, disconnect, export the log, start or stop the belt, apply a speed. Use a link only to go somewhere, such as the hosted copy. Every button is a native <button type="button">.

  • Primary (signal orange) is the one action a state exists for. On the page that is Connect; in a dialog it is the affirmative action, such as Pair or Dismiss.
  • Secondary (the default look, no modifier) is every other action: Disconnect, Export log, Set speed, Set incline, Start, Dismiss in an alert.
  • Link looks like a link but is reserved for the hosted-copy action, which ships as a.btn.btn--link because it navigates.
  • Danger appears once: Stop belt in the Stop bar. Nothing else on the page is red and solid.

Stride Link has no ghost buttons and no icon-only page buttons. The only icon-only control is the dismiss button on a toast, which is proposed in the mocks and not shipped.

Anatomy

  1. Leading icon (optional)1.25em, inherits the label colour, aria-hidden. The mocks draw one; the shipped Connect has none.
  2. LabelA verb in sentence case; it is the accessible name (L2-063).
  3. ContainerHeight from --control-height-* (44 / 44 / 52 px), --radius-md, 1px border, padding from the spacing scale.

Variants

Variants change emphasis, never meaning. Choose by how much attention the action deserves in the current state.

Sizes

Every size is at least 44 px tall because L2-061 makes 44 × 44 CSS px the floor for every control. Small exists for compact rows, not to go below the floor.

Both themes

  • Disabled is 50 % opaque and not focusable. Connect is disabled while Bluetooth is being checked, when it is unavailable, and during a run; Export log is disabled until the log has an entry (shipped canExport).
  • Busy (aria-busy="true") keeps the width, hides the label behind a spinner and ignores presses. Only set A uses it: Connect while Bluetooth is checked (pages/start/loading) and Stop belt while the stop write is in flight (pages/belt/submitting). Set B and the shipped page never show it: Connect is simply disabled and the status line says what is happening.
  • Never make Stop belt busy. A busy button ignores presses, and L2-044 requires Stop to stay enabled even after a failed write. Set A's busy Stop is drift; the system forbids it (see the Stop bar).
  • No pressed or expanded state: no toggle or menu buttons exist.

Responsive behaviour

  • Below 576 px (--layout-breakpoint-sm) buttons inside .panel__actions grow to share the row (flex: 1 1 auto), so Connect and Disconnect become wide touch targets.
  • From 576 px they return to their natural width (flex: 0 0 auto) and wrap when the row is too narrow.
  • Labels never truncate or wrap (white-space: nowrap); keep them to one or two words.
  • Height does not change with the breakpoint: 44 px is already the touch floor.

Theming

The button reads five component tokens that each variant overrides: --btn-bg, --btn-fg, --btn-border, --btn-bg-hover and --btn-bg-active. They alias semantic tokens only, so the dark theme needs no button rules.

.btn--primary { --btn-bg: var(--color-accent); --btn-fg: var(--color-fg-on-accent); --btn-border: var(--color-accent-border); }

Signal orange keeps ink text in both themes (5.6:1); white on orange is 3.3:1 and is never used. In light the primary button gets a signal-600 edge because the orange fill alone is 2.9:1 against paper; in dark the edge is the fill itself. The danger button flips from white-on-red (light) to near-black on light red (dark).

Accessibility

Role and pattern

Native <button type="button">, following the WAI-ARIA Authoring Practices Button pattern with no ARIA needed. The hosted-copy action is an <a href> because it navigates.

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the button in reading order (L2-060).
Enter, SpaceActivates the button. The link variant activates on Enter only, as links do.
EscNo effect on ordinary buttons. While the belt is active, Escape anywhere sends Stop (L2-045); see the Stop bar.

Focus

The shared ring: 2 px --color-focus-ring with a 2 px offset on :focus-visible (L2-060). The offset shows the surface between ring and button, so the ring stays 3:1 against the page even on the orange button.

Labelling

The visible label is the accessible name (L2-063). The Stop button's Esc key cap is aria-hidden and the shortcut is exposed with aria-keyshortcuts="Escape" instead, so the name stays exactly Stop belt (L2-045).

Motion

Background, border and shadow transition over --duration-fast (120 ms) and active presses down 1 px. Under prefers-reduced-motion: reduce every transition is removed (shipped rule, L2-063).

Touch

All sizes are at least 44 × 44 px (L2-061); Stop belt is 64 × 64 px. Nothing depends on hover.

Content

  • Labels are verbs or verb phrases in sentence case: Connect, Disconnect, Export log, Start, Set speed, Set incline, Stop belt, Dismiss.
  • Use the L2 names exactly. Export log and Stop belt are fixed by L2-036 and L2-045; never “Download” or “Stop”.
  • The mocks disagree on the apply buttons: set A says Apply, set B and the shipped page say Set speed and Set incline. The system uses the shipped labels because two Apply buttons in one panel are ambiguous to a screen-reader user listing buttons.
  • No “OK”, “Submit” or “Click here”.
