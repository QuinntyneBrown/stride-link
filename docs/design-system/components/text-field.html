Text field

Numeric text fields for target speed and incline, each applied by its own button and validated on apply.

Overview

The text field is the single-line input. Stride Link uses it for exactly two values, both numeric: target speed (0 to 3 km/h in steps of 0.1, L2-046) and target incline (whole numbers 0 to 15, L2-047). Each sits in a control row with the button that applies it, inside a form field.

  • Values are applied only when the tester presses the button. Typing never writes a frame.
  • The field accepts what the tester types; validation runs on apply and an out-of-range value is rejected without writing (L2-046, L2-047).
  • Use a native <input type="number"> with min, max, step and inputmode. No custom spinner.

There are no free-text, search, e-mail or password fields: the product collects nothing (L2-049, L2-052).

Anatomy

  1. InputNative number input, 44 px tall (--control-height-md), 1px --color-border-strong, --radius-md, tabular figures.
  2. Apply buttonSecondary button, natural width, top-aligned with the input; names the value it sets.

Variants

Two variants, distinguished by their constraints rather than their look.

Speed: min=0 max=3 step=0.1 inputmode=decimal.
HTML
<div class="control-row"><input class="input" type="number" min="0" max="3" step="0.1" inputmode="decimal" aria-label="Target speed (km/h)" value="1.5"><button class="btn" type="button">Set speed</button></div>
Incline: min=0 max=15 step=1 inputmode=numeric.
HTML
<div class="control-row"><input class="input" type="number" min="0" max="15" step="1" inputmode="numeric" aria-label="Target incline" value="0"><button class="btn" type="button">Set incline</button></div>

Sizes

One size: 44 px (--control-height-md). The shared kit's .input--sm and .input--lg are used by neither set nor the shipped page and are not part of this system.

States

Hover and focus are forced with data-state; invalid uses the real aria-invalid="true".

Both themes

  • Focus replaces the border with the focus colour and draws the ring flush (outline-offset: 0), so the field does not jump.
  • Invalid adds a 2 px danger edge (border plus inset shadow) and is always paired with the error message; colour is never the only signal (L2-062).
  • Disabled and read-only are documented for completeness; the shipped page never disables or locks these inputs. When the gate is closed they are removed instead (L2-042).

Responsive behaviour

  • The input flexes (flex: 1; min-width: 0) and the apply button keeps its width, so the row fits at 320 px (L2-064).
  • Below 576 px each field takes the full column; from 576 px speed and incline sit side by side in the two-column belt controls grid.
  • Numeric keypads open on touch devices through inputmode.

Theming

The input reads three component tokens: --field-bg (--color-bg-surface), --field-border (--color-border-strong) and --field-border-hover (--color-fg-muted). Invalid and focus use --color-danger-solid and --color-focus-ring directly so they cannot be re-themed away.

.input { --field-bg: var(--color-bg-surface); --field-border: var(--color-border-strong); }

Accessibility

Role and pattern

Native <input type="number"> (spinbutton role) with a visible <label for>; help and error are linked with aria-describedby, invalid with aria-invalid.

Keyboard

KeyAction
TabMoves into the input, then to its apply button.
↑ / ↓Steps the value by step (0.1 km/h or 1), clamped by the browser to min and max.
EnterIn set A the field is a <form> and Enter applies; in set B and the shipped page Enter does nothing and the button applies.
EscWhile the belt is active Escape sends Stop even from inside this input (L2-045 criterion 4).

Focus

Ring flush with the field in --color-focus-ring; the border takes the same colour.

Labelling

The visible label (Target speed (km/h), Target incline) is the accessible name (L2-063). The unit is in the label, not a placeholder.

Motion

Border and shadow transition over 120 ms; removed under reduced motion.

Touch

44 px tall (L2-061); the apply button beside it is also 44 px.

Content

  • Labels: Target speed (km/h) and Target incline (shipped and both sets).
  • Help: shipped and set B say 0 to 3 km/h, in steps of 0.1; set A drops the comma. Incline help is Whole numbers from 0 to 15 everywhere.
  • Errors are fixed by L2 and appear below the help: Speed is capped at 3 km/h for the smoke test. (above 3), Enter a speed from 0 to 3 km/h. (negative, empty or not a number), Enter a whole-number incline from 0 to 15.
  • No placeholder text: the help line carries the range.
