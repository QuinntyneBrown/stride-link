Overview

A dialog is a modal panel over a backdrop. Stride Link itself draws no dialog in the shipped page. Every dialog in the mocks is one of two kinds:

  • Browser-native surfaces drawn for flow context: the Web Bluetooth device chooser (both sets, L2-006) and the beforeunload leave-page confirmation (set B, L2-041). Their look, wording and behaviour belong to Chrome or Edge; the product can only trigger them. They carry the .native class so they read as browser chrome.
  • An app-drawn alert dialog: set A's Connection lost (L2-048). The shipped page and set B show the same L2 sentence as an inline alert in the status panel instead, which keeps Stop and the log reachable without a modal.

When a future app-drawn dialog is needed, follow the WAI-ARIA Authoring Practices Dialog (Modal) pattern, or Alert Dialog for an interruption that needs a response.

Anatomy

  1. Backdrop.backdrop: --color-bg-backdrop over the inert page. In the previews on this page the grey frame stands in for it; the HTML shown includes it.
  2. Panel.dialog__panel: --dialog-bg (raised surface), --shadow-4; at most 32 rem wide, 24 rem with --sm; --radius-lg when centred, --radius-xl top corners as a bottom sheet.
  3. Icon (optional).dialog__icon--danger: 40 px circle in danger tones, aria-hidden.
  4. Title and description.dialog__title referenced by aria-labelledby; description by aria-describedby.
  5. Body.dialog__body; the panel scrolls when taller than the viewport minus 48 px.
  6. Footer.dialog__footer: actions at the end, primary last, wrapping; sticky to the panel bottom with a top rule.

Both themes

Leave site?

Leave site?

Changes you made may not be saved.

  • Open: the page behind is inert and aria-hidden; focus moves into the dialog.
  • Closed: the dialog is removed and focus returns to the control that opened it (Connect for the chooser).
  • Set A's chooser keeps Pair enabled while scanning in its busy mock; set B disables Pair while scanning or empty. Pair needs a selected device, so disabled is correct.

Responsive behaviour

  • From 640 px (40 rem) the panel is centred with 24 px (--space-6) of padding around it and --radius-lg corners.
  • Below 640 px the panel becomes a bottom sheet: full width, anchored to the bottom edge, top corners --radius-xl; footer buttons wrap and stay end-aligned.
  • Device names wrap (overflow-wrap: anywhere), so the long unknown-device name in set A fits at 320 px.

Theming

Panel: --dialog-bg (--color-bg-surface-raised). Backdrop: --color-bg-backdrop. Icon: --color-danger-bg with --color-danger-icon. Selected device: --color-accent-subtle fill (the aria-pressed state also changes the row for assistive technology). Font: .native switches to the system UI font so browser chrome looks unlike the product. Dark mode raises the panel to ink-800.

Accessibility

Role and pattern

role="dialog" (chooser) or role="alertdialog" (Connection lost, leave-page) with aria-modal="true", aria-labelledby on the title and aria-describedby on the description. Devices are toggle buttons (aria-pressed) in a list. The previews on this page omit aria-modal and autofocus so the documentation stays usable; the HTML shown includes them.

Keyboard

KeyAction
Tab / Shift+TabCycles within the dialog; focus never reaches the inert page.
Enter / SpaceSelects a device or activates a button.
EscCloses the browser chooser as Cancel: the page returns to idle and shows No treadmill selected. (L2-009). On set A's Connection lost it dismisses. Escape-to-Stop does not apply there: once the link is lost Stop cannot be sent.

Focus

Initial focus: set A chooser Pair, set B chooser Cancel, Connection lost Dismiss, leave-page Cancel. Focus returns to the opener on close.

Labelling

Titles and buttons are named by their visible text. The danger icon is decorative.

Motion

The backdrop fades in over --duration-base and the panel slides up (sheet) or scales in (centred) over --duration-slow; under prefers-reduced-motion both appear instantly.

Touch

Device rows and footer buttons are at least 44 px tall; on a bottom sheet the buttons are full width.

Content

  • Connection lost uses the L2-048 sentence verbatim as its description: Connection lost. If the belt is moving, use the treadmill's stop button or safety key.
  • The set A body line Stride Link can no longer send Stop. The run's log and verdict are kept. is mock copy, not an L2 string; it does not ship.
  • Browser-native wording (wants to pair, Leave site?, Changes you made may not be saved.) is the browser's. Never restyle it as product copy.
  • Set A's empty chooser adds a hint, Make sure the treadmill is on and not connected to another app or phone.; set B shows only No compatible devices found.
