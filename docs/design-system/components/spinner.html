Spinner

A turning ring beside words, for a wait with no known end. In the mocks: the browser chooser's scan and set A's busy Connect.

WCAG 2.2 AAMocks only: not shippedMock sets: A and B

Overview

A spinner is a turning ring that marks a wait with no known end. Both mock sets use exactly one: Scanning for devices… in the browser's Bluetooth chooser while it looks for treadmills. That chooser is drawn by the browser, so the spinner is flow context, as the device list is. The same ring also draws the loading state of a button (aria-busy="true"), which set A uses for Connect.

  • Always pair the spinner with words; the ring alone says nothing.
  • Use a progress bar when the end is known.
  • Never put a spinner on Stop belt. See Stop bar.

Anatomy

  1. Ring20 px circle, 2 px --color-border-default with the top quarter in --color-accent, turning every 0.8 s. aria-hidden.
  2. TextThe wait in words, muted.

Responsive behaviour

  • No change across widths; the text wraps beside the ring.

Theming

Ring --color-border-default with an --color-accent arc. Both have dark values.

Accessibility

Role and pattern

Decorative: aria-hidden="true". The text beside it is the message. If the text appears while the tester waits, put it in a polite live region (the chooser's body, in the browser's real UI). A busy button uses aria-busy="true" and keeps its label for its accessible name.

Keyboard

KeyAction
NoneNot focusable.

Focus

Never receives focus.

Labelling

The ring has no name; never give it role="img" with “Loading”: the words already say it.

Contrast

Arc on panel--color-accent on --color-bg-surface-raised
Scan text on panel--color-fg-muted on --color-bg-surface-raised
Arc on panel--color-accent on --color-bg-surface-raised
Scan text on panel--color-fg-muted on --color-bg-surface-raised

Motion

Turns continuously. Under prefers-reduced-motion: reduce the animation is removed and the ring is still; the words carry the state. The ring turns for less than five seconds in the chooser, but if it ever ran longer, WCAG 2.2.2 would need a way to pause it.

Touch

Not a target.

Content

  • Text names what is happening, present participle, ending in an ellipsis character: “Scanning for devices…”.
