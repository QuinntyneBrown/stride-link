# Support

## How to get help

1. Check the [Usage](README.md#usage) and [Verdicts](README.md#verdicts) sections of the
   README.
2. Search [existing issues](https://github.com/QuinntyneBrown/beltcheck/issues) to see
   whether your question has been answered.
3. If not, open a new issue using the most fitting template. Always attach your exported
   log: it is usually enough to explain the verdict.

## Common questions

**The page says this browser can't use Bluetooth.**
Open the file in current Chrome or Microsoft Edge. Safari and iOS do not support Web
Bluetooth.

**The page says Bluetooth is blocked for files opened from disk.**
Use the hosted copy linked on the page. It is byte-identical to the release asset.

**My treadmill does not appear in the chooser.**
Make sure the treadmill is powered on, not connected to another app or phone, and within
a few metres of your device. Close the official Echelon app first.

**I got a Silent verdict.**
Export the log and open an issue. If you can, also capture the official app's pairing with
an Android HCI snoop log so the two can be compared.

## Scope of support

Stride Link is maintained on a best-effort basis by volunteers. There is no guaranteed
response time. For security issues, follow [SECURITY.md](SECURITY.md) instead.
